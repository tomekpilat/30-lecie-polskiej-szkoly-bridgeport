# 30-lecie Polskiej Szkoły w Bridgeport - strona informacyjna

Prosta, statyczna strona informacyjna dla rodziców, absolwentów i przyjaciół Polskiej Szkoły w Bridgeport. Zawiera wytyczne przygotowania życzeń, zdjęć, wspomnień, podziękowań lub reklamy do publikacji jubileuszowej z okazji 30-lecia szkoły.

## Podgląd lokalny

Uruchom dowolny prosty serwer statyczny w tym katalogu i otwórz `index.html` w przeglądarce.

## Publikacja w GitHub Pages

1. Utwórz nowe repozytorium na GitHubie.
2. Dodaj do niego całą zawartość tego katalogu.
3. W ustawieniach repozytorium wybierz **Pages**.
4. Jako źródło wybierz **Deploy from a branch**, gałąź `main` i katalog `/ (root)`.

Strona nie wymaga kompilacji ani zewnętrznych bibliotek.

## Ważna uwaga

UBuildABook określa wymagania strony książki, spadów, marginesów, rozdzielczości i PDF. Rozmiary mniejszych modułów reklamowych są propozycją organizatora, zbudowaną tak, aby bezpiecznie mieściły się w publikacji 8,5 x 11 cali.
